# IEEE CS Open

Open source from the **IEEE Computer Society Student Branch Chapter of SLIIT**.

We build tools for our own events — competition judges, registration portals,
CTF infrastructure — and release them so other student branches don't have to
build the same things from scratch.

## Contributing

New to open source? Start with issues labelled **`good first issue`**. You do
not need to be a SLIIT student, or an IEEE member, to contribute.

Read [CONTRIBUTING.md](https://github.com/ieeecsopen/.github/blob/main/CONTRIBUTING.md)
before opening a pull request.
